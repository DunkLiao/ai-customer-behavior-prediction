# 零售分析資訊圖翻頁書

這個專案是一個靜態 RWD flip book 網頁，用來瀏覽 `infographics/` 目錄中的零售分析資訊圖表。頁面支援桌機雙頁、手機單頁、縮圖導覽、鍵盤操作、觸控滑動、全螢幕放大檢視，以及深色/淺色模式切換。

## 背景說明

本專案內容源自參加工研院 2026 年 8/19、8/26「客戶數據分析：AI 解讀消費者歷史數據高效行銷實作應用班（臺北班）」的學習整理。

製作流程是將課堂中的專有名詞以 Perplexity 查詢後，再利用 ChatGPT 產生資訊圖表，最後整理成翻頁式網頁，方便集中瀏覽與複習。

## 功能特色

- 桌機版以雙頁展開呈現，接近翻書閱讀體驗。
- 手機版自動切換為單頁閱讀，並針對窄螢幕優化按鈕與縮圖排版。
- 支援上一頁、下一頁、縮圖跳頁與頁碼顯示。
- 支援鍵盤左右方向鍵與手機觸控滑動。
- 點擊資訊圖可開啟放大檢視。
- 支援深色/淺色模式切換，並記憶使用者偏好。
- 無需前端框架或建置流程，可直接以靜態網站部署。

## 本機執行

在專案根目錄啟動靜態伺服器：

```powershell
python -m http.server 8080
```

然後開啟：

```text
http://127.0.0.1:8080/
```

## 測試

本專案使用 Node.js 內建測試執行器：

```powershell
npm test
```

測試內容涵蓋：

- 資訊圖表頁序與數量。
- 桌機雙頁與手機單頁翻頁規則。
- 鍵盤與觸控滑動操作。
- 放大檢視狀態。
- 手機 RWD 版面規則。
- 頁首背景說明與頁尾署名。
- 深淺色切換與淺色模式文字可讀性。

## 專案結構

```text
.
├── index.html              # 靜態網頁入口

└── test/

```
